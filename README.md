# Учебный проект Stellar Burger
Интернет-магазин бургеров, с конструктором бургера, корзиной, личным кабинетом, историей заказа. 


### Структура проекта:

- src/ — исходные файлы проекта
- src/components/ — папка с JSX компонентами
- src/components/services/slices -  папка с слайсами и Unit-тестами
- src/components/services/store - папка с глобальным хранилищем Redux

Важные файлы:
 - src/utils/burger-api - файл с запросами к серверу
 - src/utils/types - файл с типами


## Что сделал
- подключил базу данных к проекту используя API
- настроил логирование, аутентификацию и авторизацию
- проработал роутинг для авторизированных и не авторизированных пользователей
- компонент src/components/ProtectedRoute отвечающий за доступ не авторизированного пользователя к контенту
- реализовал основную логику работы компонентов с помощью Redux Toolkit, настроил глобальный store. 
- написал Unit-тесты для слайсов;
- написал e2e тесты для главной страницы;

## Реализованный функционал
- регистрация и авторизация пользователя;
- главная страница: вывод списка товаров, статус авторизации пользователя(верхний правый угол);
- каталог товаров: подгрузка с сервера данных о товаре(состав, картинка, описание);
- корзина: сортировка ингредиентов, отправка информации о заказе на сервер; 
- вывод информации пользователю об успешном заказе, с номером заказа


## Использованные технологии

- Стек: HTML, SCSS, TS, React, Redux, Webpack, Хуки(useState, useEffect, useContext)
- использование глобального хранилища, работа с - Api.

 ## Установка и запуск
Перед запуском проекта, нужно создать файл .env в корне проекта и копировать в него код из .env.exapmle .\
Для установки и запуска проекта необходимо выполнить команды:

```
npm install
npm run start
```

или

```
yarn
yarn start
```

## Сборка

```
npm run build
```

или

```
yarn build
```

## Запуск документации Storybook

```
npm run storybook
```

## Запуск Unit-тестов

```
npm run test
```

## Запуск e2e тестов
```
npm run cypress:open
```
